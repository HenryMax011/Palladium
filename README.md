# Palladium Clínica de Estética

Site institucional em Next.js. O visual e a estrutura já estão prontos; conteúdos editáveis ficam em `src/lib`.

## Rodar

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Onde editar

- `src/lib/site.ts` — telefones, endereços, oferta do Ultraformer, horários
- `src/lib/treatments.ts` — protocolos
- `src/lib/stories.ts` — depoimentos e blog

As fotos atuais são referências do Unsplash, não imagens da clínica. Troque os endereços em `photos`, dentro de `src/lib/site.ts`, pelas fotos reais das unidades e dos tratamentos.
